# CSV Lens

CSV Lens is a small, privacy-first CSV previewer built with React, Vite, TypeScript, and Tailwind CSS. Drop in a CSV file to inspect it in a spreadsheet-like table with row, column, and empty-cell counts.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Files are parsed entirely in the browser and are never uploaded.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run preview` — preview the production build locally
