# Changelog

## [0.1.0] - 2026-11-13

### Added

- CSV upload through a file picker or drag-and-drop.
- Local CSV parsing with Papa Parse.
- Spreadsheet-like preview with sticky-style column metadata, search, and empty-cell display.
- Dataset summary for rows, columns, filtered rows, and empty cells.
- Sample dataset for trying the interface without a file.
